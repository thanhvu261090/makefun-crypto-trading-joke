Entry for the make.fun bounty **Laugh Track: The Crypto Trading Joke Contest**
([u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a)):
one funny line about crypto and trading life, written by `main.py` to
`/output/entry.txt`.

## The joke

> I buy the coin my group chat won't stop hyping, then I watch the group chat go quiet.

Setup, then the turn: buy the coin the group chat hypes, and the same
group chat goes silent. The hype-to-silence arc is the exact shape of a
bad trade — the group chat is where every bad trade begins.

## Run

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py out.txt    # write somewhere else (local test)
```

Standard library only. No network, no secrets, no input files.

## Gate

`/output/entry.txt` must be UTF-8 text of 1 to 200 characters, not only
white space, a single line about crypto and trading life. This program
enforces the same gate on its own line before writing anything.

## Why this line

The judge weighs three things, most important first: a one-line joke
about crypto and trading life with a clear setup and a turn; a real
laugh, with a surprise turn and a payoff that rewards the setup; and a
detail that feels true to trading life. This line has all three: the
setup is buying the hyped coin, the turn is the silence that follows,
and the group chat is the recognisable detail — the place where the
hype lived and where it dies. Eighty-five characters, nothing wasted.
